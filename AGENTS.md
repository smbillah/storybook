## Project rules
- Build the smallest working local Streamlit app first.
- Keep dependencies minimal.
- Ask before adding any dependency beyond streamlit, pillow, and pytest.
- Prefer simple, readable Python with type hints and docstrings.
- Use warnings instead of crashes for malformed input folders.
- After code changes, run tests or the strongest available static checks.
- Report the exact commands needed to run the app locally.
- Do not add cloud services, databases, authentication, analytics, or video features.
